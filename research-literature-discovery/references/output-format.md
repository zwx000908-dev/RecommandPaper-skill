# 输出格式

开头写课题、档案 revision、本轮需要作出的判断；实际检索日期/来源/时间窗及日期字段、内容访问深度、失败范围；给最有依据的下一步行动。

## 文献卡

每篇含以下字段，观察项可压缩或放可展开附件，但不能省掉关联与行动：

```text
标题 — 作者（可第一作者等，记录中保留完整作者）— 年份 — 来源
核验链接 / DOI / 所读版本
论文类型与状态（预印本须标该版本未经同行评审）
已核验最早公开日期 / 版本日期 / 必要的 online 与卷期日期
证据范围：全文/摘要/元数据/片段；相关章节、图表或摘要位置
核心问题 / 方法 / 原文报告的发现
作者解释（没有或未评估就说明）
具体关联：命中轴、相似点、不匹配条件
Skill 判断：推荐理由、证据限制、支持/限制/反证/竞争/迁移标签
级别与行动：读哪里、比较什么、何时重评
版本关系与变化：是否实际比较过
```

未知写未核验，仅元数据不能生成发现；科学结论就近链接来源，不用末尾链接堆代替证据。

## 按内容选择结构

只推荐少数文献时，直接给文献卡。多篇文章回答同一问题时，可列比较表：论文、可比条件、结果、分歧、仍缺证据与下一步。不为每次检索强行制作表格。

出现多条可借鉴的思路时，可以整理它们的联系、依据、困难和验证办法；只有当它有助于阅读时才做成地图。报告新增或修订内容时，区分新首发、版本变化、历史补查及课题变化后重新关联。

优先提醒、建议阅读和观察标签可用于任何请求。空类别可省略，不凑数；需要观察列表时给出实际路径或链接。报告不展示用户阶段或固定模式标签。

末尾写候选处置、未完成项、保存路径、最少待补输入（如有）和真实调度状态：未配置/已配置未运行/上次成功/部分失败。
