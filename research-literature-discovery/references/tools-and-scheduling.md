# 工具与调度依赖

本 Skill 是 Agent 执行的工作流，不自带爬虫、API 密钥或常驻服务。最低能力为读取课题、在线搜索/访问来源和输出文本；持久追踪还需可读写目录。不能联网时仅分析所给材料；不能保存时导出状态。

| 目的 | 可选来源 | 必须核查的限制 |
|---|---|---|
| 跨域发现与身份 | Crossref、OpenAlex、Semantic Scholar、学术搜索、出版社 | 覆盖、缺失元数据、配额、引用完整度 |
| 预印本 | 化学 ChemRxiv；物理/计算 arXiv；生物 bioRxiv；医学 medRxiv；其他领域对应平台 | 首发与版本日期、评审状态、索引延迟，不全领域只查 arXiv |
| 正式新进展 | 期刊在线首发、出版社 RSS/TOC、领域数据库 | 是否支持 online/update 时间、访问权限 |
| 专门检索 | PubMed/Europe PMC；可用的 SciFinder/Reaxys；WoS/Scopus；适用中文库 | 订阅、结构检索、引用导出能力 |
| 全文/版本 | 出版社、预印本、PMC、机构库、作者开放稿、用户 PDF/SI | 实际版本、许可和完整性 |

这些是候选来源，不表示已经接入或搜索。先发现实际连接器，不足再用允许的网页/RSS/API。使用 API 前检查当前官方文档，不虚构端点。付费库不可访问就记录遗漏，不绕过权限。

限流遵守 Retry-After 并有限重试；失败保存范围。替代源不等于完整替代。无引用工具可用网页寻找线索，但标明未完成完整引用追踪。

## 定时执行合同

用户明确要求持续追踪时，复用已给频率、时区、阅读量和接收位置，只问关键缺项。Codex 环境先发现 `automation_update` 相关工具并遵守实际 schema；其他环境用真实支持的调度接口，不手写假装已执行的指令。

任务输入包含稳定数据路径/可访问引用、project_id、使用本 Skill、读取最新档案、按来源水位增量检索、保存状态和报告新工作/实质变化/待核验项。不能只冻结旧课题描述。

工具返回成功才记录 provider、task_id、频率/时区、下次运行（若提供）与交付位置；实际运行日志成功才能称执行成功。后台无法读取本地档案或凭证时修复接入或报告配置未完成，不能假定继承当前环境。外部推送仅限用户指定且授权的目标。

不支持调度时写“本次为单次执行，未启用后台监测”。可给 Windows 任务计划、cron、CI 接入方案，注明必须具备真正可执行的 Agent/检索入口、存储、凭证及通知通道；Markdown 本身不是命令。未配置验证的只称接入方案。

本 Skill 不依赖其他 Skill；可将选中文献交给现有精读工具，但发现与记录不以它存在为前提。
