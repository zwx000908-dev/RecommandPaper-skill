# 验收场景

结构检查通过不代表检索召回、判断质量或长期调度成功。以下是维护本 Skill 的行为验收；可用明确标注的测试候选替身，但不得把替身当真实论文推荐。

| 输入/情境 | 可观察的通过标准 |
|---|---|
| 用户仅给问题或材料，没有提供任何阶段信息 | 直接按问题开展检索；不询问、推断或分配阶段标签 |
| 2010 年关键证据与本月外围论文并存 | 按与当前问题的关联及影响排序，旧文不因年代删除，新文不因新近性自动优先 |
| 无关键词重合，但同一中间体/机制/瓶颈 | 能说清联系就进入候选；不因字面相似度低删除 |
| 用户连续忽略反面结果 | 不自动关闭反证通道；允许调整显示长度 |
| 同工作预印本与正式版，另有勘误 DOI | 一个工作、多版本；勘误独立关联；不重复推送、不吞勘误 |
| 相似题名不同作者/数据 | 先核对身份，不能强行合并 |
| 版本号变了但正文不可得 | 标变化待核验，不编造变化内容；保留核查项 |
| 一个来源失败或分页截断 | 其水位不前推，报告缺口；其他来源独立成功 |
| 同轮需要背景、反证与新方法，另有两个同名课题 | 检索可以组合；只为区分课题追问，不要求先选择固定模式、不串写 |
| 阅读预算为 3，另有 7 个弱相关 | 3 个重点卡片与实际可浏览观察列表；不静默过滤 |
| 用户改假设/条件 | revision 增加，检索概念更新，观察/排除记录重评 |
| 无网络、无调度或后台无文件权限 | 明确能力边界；单次材料分析/接入方案，不声称持续监控 |
| 没检索到最近邻 | 报告查询/日期/来源范围，不宣称首创 |

建议先用同一候选集人工核查不同问题下的取舍，再在获准的真实课题上做单次试运行。真实召回率需要人工标注参考集合；长期可靠性需要实际调度运行记录，不能从本文件推断。
